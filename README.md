# Little Lemon Project

[Visit the site here](https://littlelemon.software.mintrishere.com/)

![image](https://github.com/user-attachments/assets/42d4b8a1-1058-40a1-8338-cd541b68f7d8)

This project is a modern web application built using **Next.js**, **ShadCN/UI**, **TypeScript**, **Apollo Client**, and **Vercel** for deployment. The back-end is powered by **WordPress** (Headless CMS) which exposes data through **GraphQL** to provide blog and user data.

## Tech Stack

- **Next.js** for server-side rendering and static site generation.
- **ShadCN/UI** for building modern, customizable user interfaces.
- **Apollo Client** for interacting with the GraphQL API provided by the back-end.
- **Headless WordPress CMS** for content management (blog, user data).
- **GraphQL API** for fetching blog posts, user information, and other dynamic content.
- **Deployed on Vercel** for efficient hosting and continuous deployment.
- **Responsive design** for mobile and desktop devices.

## Features & Functionality
- **Home Page**: Displays featured content, such as blog posts and dynamic content fetched from WordPress via GraphQL.
- **Blog**: A list of blog posts fetched from the WordPress GraphQL API.
- **User Dashboard**: Allows users to manage their profile and settings.
- **Responsive Design**: The app is fully responsive, adapting to both mobile and desktop screen sizes.
- **Subscription**: Users can subscribe to newsletters and updates.
- **Authentication**: Managed using Apollo Client for seamless user login and sign-up processes.
